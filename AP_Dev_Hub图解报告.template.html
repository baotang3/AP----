0. 一句话定位

AP_Dev_Hub 不是一个单一项目，而是德勤 IDDC（Deloitte Innovation & Development Center）AP 研发部门的一整套代码资产集合：一条 AI Agent 主线（Python + Vue，当前最活跃）、一套勤栈 d.orbit 低代码平台（Java 微服务，基于开源脚手架二开）、以及一批设计与 POC 展示资产（静态站点）。

7. 风险清单与建议

高风险

#问题建议
1两套 AI 实现并存，前端重复建设（Claude SDK vs Dify 封装；Alpine vs Vue）确认现行版本，另一套 deprecated 或合并
2SonarQube token 硬编码（service_ai/.gitlab-ci.yml、service_base/.gitlab-ci.yml）迁移到 GitLab CI 变量
3CI 只做质量门禁不交付：7 个 CI 全只有 verify+sonar，无 build/deploy stage、无 Dockerfile、无 K8s 清单；ap_admin_ui 甚至无 CI补齐构建与部署流水线

中风险

#问题
4文档缺失：4 个仓库 README 仍是 GitLab 默认模板（ap_dorbit_api / ap_agent_poc / ap_poc_center / ap_skills），最大仓库 ap_dorbit_api 完全无文档
5ap_admin_ui README 与代码脱节（写 npm run dev，实际无 dev 脚本，只有 start/sit/build:*）
